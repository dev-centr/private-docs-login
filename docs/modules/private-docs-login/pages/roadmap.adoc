None of this blocks registering the app or deploying `login.devcentr.org`.
Organizations can install a public GitHub App from `https://github.com/apps/private-docs-login` without a Marketplace listing.

== GitHub Marketplace listing

A Marketplace listing needs more than the app has today:

* A privacy policy URL. It has to say what the issuer reads (organization installations and the verified primary email), what it stores (short-lived sign-in rows in D1, minutes long), and what it sends to a documentation site (the ID token claims).
* Purchase webhooks. Marketplace sends `marketplace_purchase` events, so the app needs a webhook URL and secret, and the issuer needs an endpoint that verifies the signature, even for a free plan. The app is registered today with no webhook.
* Listing text, a logo, a support URL, and a terms of service URL.
