# Bundled font

`space-grotesk-latin-wght-normal.woff2` is Space Grotesk (variable weight 300-700, Latin subset) from
`@fontsource-variable/space-grotesk` 5.3.0. Copyright 2020 The Space Grotesk Project Authors
(https://github.com/floriankarsten/space-grotesk). SIL Open Font License 1.1, in `OFL.txt`.
It matches the DevCentr font lock (`dev-centr/devcentr.org/.devcentr/fonts.sdl`, role ui_sans).
Monospace text uses the platform's monospace face, so no second font ships.
